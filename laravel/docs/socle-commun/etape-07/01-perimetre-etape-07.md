# Périmètre Étape 7

Cette étape ne modifie pas encore les contrats fonctionnels des formulaires complets. Elle retire les sources locales parallèles des référentiels déjà branchés et validés à l'étape 6.

Restent volontairement hors périmètre de cette étape :

- harmonisation complète des champs Entreprise / Artisan / Grossiste ;
- migration des usages/garanties produit qui ne sont pas encore tous exposés dans le référentiel central ;
- centralisation complète des statuts/actions de commandes ;
- nettoyage général des warnings Flutter existants ;
- suppression d'autres fichiers morts sans lien avec les référentiels.
